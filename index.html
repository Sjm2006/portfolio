ABOUT ME

I'm a BCA student at Techno India, Salt Lake — working across the web stack with JavaScript, React, and Python. Over the past two years, I've shipped projects that range from a WebSocket-powered multi-user drawing tool (deployed on Railway) to a TypeScript health dashboard built under hackathon pressure.

My process is simple: pick a problem, start building, hit the walls, understand why they're there. That cycle is still how I learn best.

WHAT DRIVES ME

Mostly curiosity. I want to understand how things actually work — not just get them working. That's what pulls me toward API design, data structures, and thinking about state management even when the course doesn't require it.

I build tools I'd actually use. Clean interfaces, predictable logic, and UIs that don't make users think too hard — these aren't things I say to sound like a developer. They're just what I aim for every time I open a code editor.

CANVAS COLLAB BY SJM

Multi-user collaborative drawing app built on the HTML5 Canvas API with a WebSocket server handling real-time state sync. Every stroke, colour change, and tool action is broadcast instantly across connected clients — each session maintains consistent shared state through event-driven messaging. Deployed and live on Railway.

HTML5 Canvas JavaScript WebSockets Real-Time Collaboration Creative Tools

ACE MY STUDY

Client-side study planner that generates personalised schedules based on subjects, exam dates, and self-assessed difficulty. All data lives in the browser via the localStorage API — no backend, no account required. Progress and session trends are visualised with Chart.js. The architectural decision to go fully client-side keeps it fast, private, and dependency-free.

HTML5 CSS3 JavaScript LocalStorage API Chart.js

Health assessment dashboard built with React, TypeScript, and Vite — submitted as a national hackathon entry. Users input health metrics and receive visual feedback through Recharts data visualisations. Radix UI provides the accessible component primitives. First production-level TypeScript project, built under actual deadline pressure.

TypeScript React Vite Radix UI Lucide React Recharts

Weather app that fetches live data from the WeatherAPI and renders current conditions plus a 5-day forecast for any searched location. Handles async API calls with proper error states and empty-location fallbacks. Displays temperature, humidity, wind speed, and atmospheric pressure in a clean, fully responsive layout.

COINFLIP ON-CHAIN

A provably-fair on-chain coin flip dApp built with a Rust smart contract deployed to the Stellar Testnet via the Soroban platform. Players bet XLM, call the flip function, and win double their stake at 50/50 odds — all enforced by the contract, not a server. Integrated Freighter wallet for transaction signing and XLM token transfers directly through the Soroban SDK.
